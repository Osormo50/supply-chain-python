# Supply Chain Python

Python projects applying supply chain concepts to realistic planning problems.
Each project includes the business problem, formulas, sample output, and a what-if scenario.

> All data is made up for learning purposes.

## Projects

| # | Project | Supply chain concept | Python concepts |
|---|---|---|---|
| 01 | [Reorder Point Simulator](01-reorder-point-simulator) | Reorder point, lead time, safety stock | functions, while loops, if/else |
| 02 | [Dock Capacity Analysis](02-dock-capacity-analysis) | Capacity, utilization, peak vs average | for loops, accumulators, if/elif |
| 03 | [Item Master Report](03-item-master-report) | Item master, single-source risk, where-used | nested dictionaries, loops, `in` |
